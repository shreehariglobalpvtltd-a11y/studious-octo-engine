# Live Fleet — वेबसाइटमा राख्ने तरिका (सजिलो नेपालीमा)

यो प्याकेज **shreehariglobal.in** मा राख्नका लागि हो। सबै फाइल **नयाँ** हुन् — पुरानो कुनै फाइल मेटिँदैन।
जडान गर्दा दुई फाइलमा मात्र केही लाइन थपिन्छ (`admin/_guard.php` मा मेनु, `admin/map.php` मा पुरानो नक्सामा बस देखाउने),
र तिनको **ब्याकअप** (`….bak`) आफैं बन्छ। सम्भव भए पहिले **टेस्ट कपी**मा गर्नुहोस्।

## प्याकेजभित्र के छ

| फोल्डर | के हो |
|---|---|
| `1-upload-to-public_html/` | वेबसाइटको `public_html` भित्र अपलोड गर्ने फाइलहरू (उही फोल्डर संरचना) |
| `2-menu/` | हातैले गर्नुपरे: मेनुका ५ लाइन (`MENU-5-LINES.txt`) र patch फाइलहरू |
| `3-database/` | डाटाबेसको SQL (१० नयाँ टेबल) — installer ले आफैं चलाउँछ |
| `4-tools/` | टेस्ट गर्ने सिमुलेटर, डेमो ड्राइभर, SSH install स्क्रिप्ट |
| `docs/` | CCTV जोड्ने तरिका, अनुसन्धान, स्क्रिनसट |

---

## चरण ० — ब्याकअप (अनिवार्य)

Hostinger → **File Manager** मा `public_html` को zip ब्याकअप लिनुहोस्, र **phpMyAdmin → Export** बाट डाटाबेसको पनि।

## चरण १ — फाइल अपलोड

`1-upload-to-public_html` **भित्रका** सबै फोल्डर र फाइल (`admin`, `api`, `assets`, `cron`, `database`, `driver`, `includes`, `tests`, `bus-live.php`)
वेबसाइटको `public_html` मा अपलोड गर्नुहोस्। "Replace?" सोध्यो भने — पहिलो पटक सोध्नु हुँदैन (सबै नयाँ फाइल)।
नयाँ संस्करण राख्दा भने **Replace** गर्नुहोस्।

## चरण २ — एक क्लिकमा जडान ⚡

ब्राउजरमा **super-admin** भएर खोल्नुहोस्:

```
https://www.shreehariglobal.in/admin/live-install.php
```

**⚡ Install all** थिच्नुहोस्। यसले:
- डाटाबेसमा १० नयाँ टेबल बनाउँछ (पुरानो केही बदलिँदैन, दोहोर्‍याए पनि केही बिग्रिँदैन)
- एडमिन मेनुको **Map** मा *Live Fleet*, *TV Wall*, *Vehicles & Drivers* थप्छ
- पुरानो **Live Map** मा पनि सबै बस देखाउँछ (Google Map जस्तै रङमा)

हरेक चरणमा ✓ देखियो भने सकियो। कुनै ✗ आयो भने त्यहीँ लेखेको कारण पढ्नुहोस् — फाइल लेख्न नमिलेमा तलको "हातैले" तरिका।

<details><summary>हातैले गर्ने तरिका (installer चलेन भने मात्र)</summary>

1. **मेनु:** `public_html/admin/_guard.php` खोल्नुहोस्, `'Live Map'` भएको लाइन खोज्नुहोस्, त्यसको **ठीक तल**
   `2-menu/MENU-5-LINES.txt` का ५ लाइन पेस्ट गरेर Save।
2. **डाटाबेस:** phpMyAdmin → डाटाबेस छान्ने → **Import** → `3-database/upgrade-2026-10-live-fleet.sql` → **Go**।
3. **पुरानो Live Map** (ऐच्छिक): `2-menu/admin-map.patch` मा `+` भएका लाइन `admin/map.php` मा उही ठाउँमा थप्ने।
4. **SSH छ भने:** `bash 4-tools/install.sh /var/www/shreehariglobal.in/public_html` (मेनु + Live Map), र
   `cd public_html && php tests/apply-sql.php database/upgrade-2026-10-live-fleet.sql` (डाटाबेस)।
</details>

## चरण ४ — गाडी नम्बर अनुसार फोन जोड्ने 📲

1. **Admin → Map → Vehicles & Drivers**। हरेक **गाडी नम्बर**को लाइनमा:
   - **Assigned driver** मा त्यो बसको नियमित ड्राइभर छान्नुहोस् (आफैं Save हुन्छ)।
   - **📲 Pair a phone** थिच्नुहोस् → ६ अङ्कको **कोड** र **QR** आउँछ (१५ मिनेट, एक पटक मात्र चल्छ)।
2. बसमा सधैं रहने फोनमा (पुरानो Android भए पनि हुन्छ, Chrome):
   - QR स्क्यान गर्नुहोस्, **वा** `https://www.shreehariglobal.in/driver/` → **🚌 Bus phone** → कोड टाइप → **Connect**।
   - **Location → Allow**। फोन आफैं सुरु हुन्छ र हरेक सेकेन्ड GPS पठाउँछ।
   - फोन **चार्जरमा**, **स्क्रिन खुला** राख्नुहोस्। (Settings → Display → Screen timeout लामो; Battery saver बन्द।)
   - पछि फोन रिस्टार्ट भए पेज खोल्दा १० सेकेन्डमा आफैं सुरु हुन्छ।
3. ड्राइभरको आफ्नै फोनबाट चलाउने हो भने: **Driver logins** मा **Driver ID** (जस्तै `D101`) + **PIN** (🎲) → **Give login** →
   ड्राइभरले `/driver/` मा लगइन गर्छ → उसको तोकिएको बस आफैं छानिएको हुन्छ → **▶ Start trip**।

फोनले के-के पठाउँछ: लोकेसन, गति, दिशा, GPS को शुद्धता, उचाइ (हरेक सेकेन्ड); ब्याट्री %, **चार्जर लागेको छ कि छैन**,
नेटवर्क (4G / Wi-Fi), एप स्क्रिनमा छ कि छैन। चार्जर निकालियो, ब्याट्री २०% भन्दा कम, वा एप पछाडि गयो भने अफिसमा सूचना आउँछ।

## चरण ५ — हेर्ने

1. **Admin → Map → Live Fleet** — सबै बस **गाडी नम्बर** सहित, हरेक सेकेन्ड अपडेट, Google Map जस्तै रङ।
   बस थिच्दा: हाम्रो सेतो बसको फोटो + लोगो, नम्बर प्लेट, गति, अहिले कहाँ, अगाडिका ठाउँ (किमी / मिनेट),
   **रेलवे जस्तै स्टप-स्टपको स्थिति** (तालिका समय, पुगेको समय, ढिलो/छिटो), नजिकैका मन्दिर, ड्राइभरलाई फोन / WhatsApp,
   **⏪ Replay** (पुरानो यात्रा भिडियो जस्तै), **📲 Send link** (यात्रुको परिवारलाई लाइभ लिंक)।
2. **🔊** थिच्नुहोस् — हरेक ठाउँ पुग्दा 🔔 घण्टी र नेपाली आवाज। ⚙️ मा आवाज, गति, घण्टी छान्न सकिन्छ।
3. **TV:** Vehicles & Drivers मा **➕ Make TV link** → त्यो लिंक टिभीमा **Microsoft Edge** मा खोल्ने (नेपाली आवाज Edge मा राम्रो छ) →
   **⛶ Full screen** → **🔊** एक पटक थिच्ने। **🚉 Board** थिचे रेलवे स्टेसनको जस्तै सबै बसको तालिका देखिन्छ।
4. ड्राइभरले 🆘 थिचे — टिभी र Live Fleet मा **रातो सूचना + साइरन**, नक्सा त्यही बसमा जान्छ। समाधान भएपछि **✓ समाधान** थिच्नुहोस्।

फोन हरायो? Vehicles & Drivers → **Attached phones** मा **Sign out**, वा त्यो बसको लागि नयाँ फोन जोड्नुहोस् (पुरानो आफैं बन्द हुन्छ)।

## बस नचलाई टेस्ट (टेस्ट कपीमा मात्र)

```bash
php 4-tools/fleet-demo-seed.php /path/to/test-site       # DEMO1–3, PIN 1234 + बाटोका नमुना ठाउँ/मन्दिर
php 4-tools/fleet-simulator.php --base=https://test.example.com \
    --driver=DEMO1:1234:1 --driver=DEMO2:1234:2 --driver=DEMO3:1234:3 --speedup=10
```

तीनवटा नक्कली बस NH48 (सुरत → मेहसाणा) मा चल्छन्। ⚠️ लाइभ साइटमा नचलाउनुहोस् — साँच्चैका बसको डट सर्छ।

## केही समस्या भए

| समस्या | समाधान |
|---|---|
| फोनमा "Location is blocked" | Chrome → साइट सेटिङ → Location → Allow |
| स्क्रिन बन्द हुँदा लोकेसन जाँदैन | स्क्रिन खुला राख्ने, चार्जरमा राख्ने; वा *Background mode* मा लेखेजस्तै **Traccar Client** एप |
| "That code is wrong or expired" | कोड १५ मिनेट र एक पटक मात्र चल्छ — Vehicles & Drivers मा फेरि **📲** थिच्नुहोस् |
| ठाउँ / मन्दिरको नाम आएन | सर्भरले `overpass-api.de` सम्म पुग्न सकेन — Settings मा `fleet_overpass_url` = `https://overpass.kumi.systems/api/interpreter` |
| आवाज आएन | 🔊 एक पटक थिच्नुहोस्; टिभीको भोल्युम; नेपाली आवाजका लागि Edge, वा Android मा Google TTS → नेपाली डाउनलोड |
| नक्सा Google जस्तै देखिएन | पेज Ctrl+F5 (cache) — रङ आफैं लाग्छ; इन्टरनेट चाहिन्छ |
| CCTV | `docs/CCTV.md` हेर्नुहोस् |
